Demo Instructions

This add-in showcases how to use event-based activation to handle the OnAppointmentAttendeesChanged, OnAppointmentTimeChanged and OnAppointmentAttachmentsChanged events.

For more information, see Activate your add-in with events.

  • Add a required or optional attendee. A notification message appears that shows a running tally of how many required and optional attendees have been invited to the meeting request.
  • Add a distribution list as a required or optional attendee. An additional notification message appears warning that a distribution list will receive this meeting request.
  • Make a change to the meeting date or time. A notification message appears displaying the original date and time. This is very handy when editing existing appointments so you can easily refer back to the original date and time.
  • Add an attachment.
  • A copy of the attachment is added with "encrypted_" prefixed to the original file name. This uses insecure XOR obfuscation for demonstration only; don't use it in production.
  • The encrypted attachment is then decrypted and added as a third attachment with "decrypted_" prefixed to the original file name.
